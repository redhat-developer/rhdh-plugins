# PR Compass

PR Compass is a personal triage board of ranked open pull requests awaiting the signed-in developer's review.

## Packages

| Package                                                            | Role                                                                           |
| ------------------------------------------------------------------ | ------------------------------------------------------------------------------ |
| [plugins/pr-compass-backend](plugins/pr-compass-backend/README.md) | Backend API and services for retrieving pull reqests from registered providers |
| [plugins/pr-compass-node](plugins/pr-compass-node/README.md)       | The `PullRequestProvider` interface and its extension point                    |
| [plugins/pr-compass-common](plugins/pr-compass-common/README.md)   | Types and permissions shared with the frontend.                                |

Installation, configuration, permissions, and the API are documented in the [backend plugin README](plugins/pr-compass-backend/README.md).
