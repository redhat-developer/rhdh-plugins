Add Saved Prompts: create, list, and delete personal prompt templates from a settings panel (with enable/disable toggle and backend limit validation). Saved prompts appear in the chat history sidebar with search, expand/collapse, show all/less, a gear shortcut to settings, click-to-apply into the message input, and kebab actions (apply, send directly, delete). Settings state is shared between the sidebar and panel; fullscreen mode syncs the open tab via URL.
